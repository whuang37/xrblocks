# Integrations

Set up the packages, providers, and hosting your application uses.

- [Dependencies and module loading](/integrations/dependencies) explains required
  and optional packages, import maps, bundlers, and asset loading.
- [AI providers and credentials](/integrations/ai-providers) explains Gemini and
  OpenAI configuration, local prototype credentials, and production authentication.
- [Build and deploy](/integrations/build-and-deploy) explains build output,
  hosting paths, secure origins, and checking the deployed app.

Follow the relevant [SDK guide](/sdk) after setup, or choose a complete
[example](/examples). Feature-specific examples include their own dependency maps.
