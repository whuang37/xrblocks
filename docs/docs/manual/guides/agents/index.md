# Build with agents

Give a coding agent the same public SDK documentation and examples a developer
would use. Keep the task small enough that the result can be exercised and
reported with evidence.

## Choose the next step

- [Agent quickstart](/get-started/agent-quickstart): create the first application.
- [Find documentation and APIs](/agents/documentation): retrieve page source,
  example source, and the contract for the installed package.
- [Build and verify](/agents/workflow): modify an app and test the requested outcome.

An agent should reuse SDK-owned startup, rendering, UI, and interaction rather
than generate parallel infrastructure. It should verify a public operation before
using it and report device/provider checks it could not run.

No skill installation is required.
