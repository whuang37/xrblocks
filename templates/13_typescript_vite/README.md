# TypeScript and Vite

Start a typed XR Blocks application with Vite.

## Run

From this folder, run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

The project includes the built-in UI and simulator panel dependencies. To build
and inspect the production output, run `npm run build`, then `npm run preview`.

Follow the [developer quickstart](https://xrblocks.github.io/docs/get-started/developer-quickstart/)
to replace the cube with an interactive spatial panel.

## Controls

Click, pinch, or use a controller trigger to change the rotating cube color.
