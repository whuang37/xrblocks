# xb-ui: core flex spatial UI

XR Blocks uses one core spatial UI system, implemented in `src/ui` and exported
from `xrblocks`. The former `SpatialPanel` grid and separate `uiblocks` addon
are not current APIs.

Use [`../xb-uiblocks/SKILL.md`](../xb-uiblocks/SKILL.md) for the complete flex
layout, styling, interaction, manipulation, and placement pattern. The smallest
working example is `samples/uiblocks/index.html`.
