# SDK guides

Choose the behavior your application needs. Each guide explains setup, ownership,
expected results, and limits, then links to runnable source and public reference.

| Task                          | Guide                                                                                  |
| ----------------------------- | -------------------------------------------------------------------------------------- |
| Organize application behavior | [Engine and Script lifecycle](/sdk/lifecycle)                                          |
| Control startup               | [Configuration](/sdk/configuration)                                                    |
| Build panels and forms        | [Spatial UI](/sdk/ui)                                                                  |
| Select or move objects        | [Input](/sdk/input) and [interaction](/sdk/interaction)                                |
| Position content              | [Placement](/sdk/placement) and [anchors](/sdk/anchors)                                |
| Read room geometry            | [Planes/meshes](/sdk/world/surfaces) and [depth](/sdk/world/depth)                     |
| Detect people or objects      | [Detection](/sdk/world/detection)                                                      |
| Connect AI to the scene       | [AI](/sdk/ai), [Live tools](/sdk/ai/live), [context](/sdk/context)                     |
| Present assets and media      | [Models](/sdk/models), [camera](/sdk/camera), [media](/sdk/media), [audio](/sdk/audio) |
| Add physical behavior         | [Physics](/sdk/physics)                                                                |
| Control image output          | [Rendering](/sdk/rendering)                                                            |
| Develop on desktop            | [Simulator](/sdk/simulator) and [verification](/sdk/verification)                      |

Start with the [quickstart](/get-started/developer-quickstart) if the engine is
not running yet. Use [examples](/examples) to combine these capabilities.
