# Flex UI

XR Blocks includes a world-space flex UI built on `@pmndrs/uikit`. It is part
of the main `xrblocks` entry. There is no separate `uiblocks` addon or UI
manager.

Use `UICard` for each world-space surface. Compose it with `UIPanel`, `UIText`,
`UIImage`, `UIIcon`, and `UIButton`. The renderer configures UIKit clipping and
transparent painter order during `xb.init()`.

## Setup

Browser import maps must provide the UIKit peer packages used by the SDK. The
complete map is in <CodeSearchLink path="samples/uiblocks/index.html" />. App
code imports every public UI type from `xrblocks`:

```js
import * as THREE from 'three';
import {UIButton, UICard, UIIcon, UIImage, UIPanel, UIText} from 'xrblocks';
import * as xb from 'xrblocks';
```

UI rendering is part of core and does not need an option or setup call.

## Basic surface

Create the card and add it to its owning script. The script lifecycle updates
the UIKit layout automatically.

```js
class MenuScript extends xb.Script {
  init() {
    const card = new UICard({
      name: 'Main menu',
      sizeX: 0.8,
      sizeY: 0.5,
      position: new THREE.Vector3(0, 1.5, -1.2),
    });
    this.add(card);

    const panel = new UIPanel({
      width: '100%',
      height: '100%',
      flexDirection: 'column',
      justifyContent: 'center',
      alignItems: 'center',
      gap: 16,
      padding: 24,
      fillColor: '#16181dee',
      cornerRadius: 24,
      strokeWidth: 2,
      strokeColor: '#ffffff44',
    });
    card.add(panel);

    panel.add(new UIText('Main menu', {fontSize: 32, color: '#ffffff'}));
    panel.add(
      new UIButton({
        label: 'Continue',
        width: 220,
        height: 72,
        fillColor: '#2b2f3a',
        cornerRadius: 18,
        justifyContent: 'center',
        alignItems: 'center',
        onClick: () => console.log('Continue'),
      })
    );
  }
}
```

`UIButton` activates only when a selection starts and ends on the same button.
Its `disabled` property uses the shared interaction barrier and semantic state.
`UIPanel` still supports low-level hover and click hooks for custom controls.

## Layout and appearance

- `sizeX` and `sizeY` set the physical card size in meters.
- `pixelSize` maps layout units to meters.
- Use flex properties such as `flexDirection`, `justifyContent`, `alignItems`,
  `gap`, `padding`, and percentage sizes.
- Use `fillColor`, `cornerRadius`, `strokeWidth`, `strokeColor`, and the inner
  or drop-shadow properties for panel appearance.
- Text, image, and icon setters update existing elements without rebuilding the
  tree.

## Manipulation and placement

Cards use the same manipulation configuration as every other scene object.
`manipulation: true` enables translation and scaling. Card translation faces
the camera by default. `manipulationEdge` separately adds the shader edge:

```js
const card = new UICard({
  sizeX: 0.8,
  sizeY: 0.5,
  manipulation: true,
  manipulationEdge: true,
});
```

`manipulationEdge` only creates the edge child. It does not enable actions on
the card. Configure both options when the edge must move or scale the card.

Set `faceCamera: false` when dragging must preserve the card orientation:

```js
const fixedOrientationCard = new UICard({
  manipulation: {
    actions: {translate: {faceCamera: false}, scale: true},
  },
  manipulationEdge: true,
});
```

Use `mode: 'spherical'` with `faceCamera: true` when the card should tilt toward
the camera instead of staying upright. Both the card drag and `FaceCamera` use
the same smoothing model for the transition.

Placement behaviors are normal child scripts. `FaceCamera`, `FollowHead`,
`FollowObject`, and `VisibilityTransition` suspend and rebase automatically
while the card is manipulated.

```js
card.add(
  new xb.FollowHead({
    offset: new THREE.Vector3(0, -0.1, -1.2),
    smoothing: 0.1,
  }),
  new xb.FaceCamera({mode: 'spherical', smoothing: 0.1})
);
```

handle configuration, and <CodeSearchLink path="samples/uiblocks/index.html" />
