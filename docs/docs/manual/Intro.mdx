# XR Blocks documentation

Build spatial interfaces, interact with 3D objects, read the world around the user,
and connect AI to an XR scene. Start in the desktop simulator, then check the
features your app needs on its target device.

| I want to…                        | Start here                                                |
| --------------------------------- | --------------------------------------------------------- |
| Build my first app                | [Developer quickstart](/get-started/developer-quickstart) |
| Build with a coding agent         | [Agent quickstart](/get-started/agent-quickstart)         |
| Add a feature                     | [SDK guides](/sdk)                                        |
| Find runnable code                | [Examples](/examples)                                     |
| Set up dependencies or a provider | [Setup guides](/integrations)                             |
| Diagnose a problem                | [Troubleshooting](/sdk/troubleshooting)                   |
| Look up a public API              | [API reference](/api)                                     |

The SDK owns the renderer, XR entry flow, frame loop, input routing, and built-in
UI renderer. Your app adds objects and behavior through Scripts.

## Start with working code

The [developer quickstart](/get-started/developer-quickstart) takes you from a
new project to an interactive spatial panel. For other starting points, try the
[Basic scene](/templates/Basic), [spatial UI](/templates/Spatial-UI), or
[object interaction](/templates/Object-Interaction). Each template page includes
a preview and its source. The [example catalog](/examples#starters) describes
requirements and links the complete projects.

For TypeScript, use the [Vite project](/get-started/installation#vite-configuration).
For an assistant that can inspect an app, start with [scene context](/sdk/context).

## Documentation and source

Use the [public API reference](/api) for signatures and defaults. Check the
installed package's version before copying an example from a different revision.
The [documentation access guide](/agents/documentation) explains source access
and version matching.
