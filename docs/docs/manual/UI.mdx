# Spatial UI

The current XR Blocks spatial UI is the core flex system exported from
`xrblocks`: `UICard`, `UIPanel`, `UIButton`, `UIText`, `UIImage`, and `UIIcon`.
It replaces the former `SpatialPanel` grid and the separate `uiblocks` addon.

Read [Flex UI](UIBlocks.mdx) for setup, layout, controls, placement, and shared
manipulation. Use <CodeSearchLink path="samples/uiblocks/index.html" /> as the
working browser example.
